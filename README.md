⚔️ Blade Rush

Blade Rush is a fast-paced Android fruit slicing game. Slice fruits, build combos, and chase your highest score.

🎮 Features

🍎 Fast fruit-slicing gameplay

⚔️ Swipe controls

🔥 Combo system

💥 Combo messages like Double Slice and Triple Slice

🏆 Score & high score

🔊 Sound effects and background music

📴 Fully playable offline

⚡ Lightweight and fast

🕹️ How to Play

Swipe across the screen to slice fruits.

Slice multiple fruits in one swipe to create combos and increase your score.

📱 Platform

Android

🚀 Build

Clone the repository:

git clone https://github.com/TechVixx/blade-rush.git

Open the project in Android Studio and build the app.
